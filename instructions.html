How to use CampusFix

Read this once and you are ready to go.

For students

  1. Click Register, enter your name, email and a password (6+ characters with letters and numbers).
  2. Login with the same email and password. You will land on your Dashboard.
  3. Fill the Report an issue form: title, category, location, priority and a clear description.
  4. Press Submit issue. It appears in My issues with the status Pending.
  5. Use search and filters to find older issues. You can delete your own issue if it was reported by mistake.
  6. Press Logout when you are finished, especially on shared computers.

Understanding status

  • Pending Your issue is received and waiting to be checked.
  • In Progress The team is working on it.
  • Resolved The problem has been fixed.

Priority levels

  • High Safety risk or something affecting many people (no water, power cut).
  • Medium Important but not an emergency (slow WiFi in a block).
  • Low Minor problem (a broken chair).

For admins / staff

  1. Register as Admin / Staff using the access code from the campus office, or use the demo admin account on the login page.
  2. Open the Admin Panel to see every issue and the totals at the top.
  3. Change an issue's status using the dropdown on its card. The student sees the update on their dashboard.
  4. Use search and filters to focus on urgent categories first.

Good reporting tips

  • Write a short, specific title (for example "No water in Block 32, 2nd floor").
  • Give the exact location so staff can find it quickly.
  • Mention since when the problem has been happening.
  • Report each problem separately, one form per issue.

FAQ

I forgot my password. What now?

This demo stores accounts in your browser only, so there is no reset. Register again with a new email.

Why can I not see my issues on another device?

Data is saved in the browser you used (localStorage). A full version would use an online database.

Can other students see my issues?

No. Students see only their own issues. Admins can see all issues.

Is my data safe?

Passwords are not stored as plain text, but this is a learning project. Do not use a password you use elsewhere.
